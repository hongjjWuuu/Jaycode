# Jaycode Agent Rules

- Prefer the repository workspace as the first source of truth.
- Read `AGENTS.md`, `README.md`, and nearby evidence files before guessing.
- Keep the agent read-only unless the user explicitly authorizes a write or command action.
- Prefer concise, structured outputs.
- When a request has multiple steps, complete them in order.
- If a task is ambiguous, gather evidence before answering.
